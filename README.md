# DAH Attention Exchange

A production-grade attention economy platform built under DAH Enterprise.

## Vision

Connect users, advertisers, and creators through a transparent attention exchange system.

## Repository Status

Current phase: Pass 1 - Foundation and Monorepo Setup

## Stack

- TypeScript
- Next.js
- Node.js
- PostgreSQL
- Drizzle ORM
- Redis
- Docker
- pnpm workspaces
- Turborepo

## Development

Install dependencies:

```bash
pnpm install
```

Run development:

```bash
pnpm dev
```
