# DAH Attention Exchange Master Specification

## Vision

DAH Attention Exchange is a verified attention marketplace connecting users, creators, and advertisers through a transparent reward economy.

## Core Product Loop

User attention -> Proof of Attention -> Reward Engine -> Wallet Ledger -> Analytics

## Core Domains

- Identity and Trust
- Attention Engine
- Reward Economy
- Wallet and Ledger
- Campaign Marketplace
- Creator Economy
- Fraud Intelligence
- Analytics
- Enki Intelligence Layer

## Engineering Direction

Build complete vertical product slices rather than isolated scaffolding.

Each subsystem should include:

- Domain models
- Application services
- Infrastructure adapters
- API contracts
- Validation
- Tests
- Documentation
- Security considerations

## Intelligence Layer

Enki provides:

- Recommendations
- Campaign optimization
- Fraud analysis
- User modeling
- Platform insights

## Initial Production Flow

1. User identity established
2. Campaign selects eligible audience
3. Attention session begins
4. Signals are collected and verified
5. Reward is calculated
6. Ledger transaction is created
7. Wallet projection updates
8. Analytics events are recorded

## Quality Standard

Prioritize correctness, security, scalability, maintainability, and a coherent user experience.
